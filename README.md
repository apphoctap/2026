# Quản lý & Giao đề thi tự học

Ứng dụng một file (`index.html`) chạy trực tiếp trên GitHub Pages.

## Đăng lên GitHub Pages
1. Tạo repository mới, tải lên `index.html`, `.nojekyll`, `README.md`.
2. Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `(root)` → Save.
3. Sau 1–2 phút truy cập: `https://<tên-tài-khoản>.github.io/<tên-repo>/`

## Cập nhật CODE116
- Bảng nhập từ Word: luôn trải đều 2 bên khung đề (máy tính và điện thoại).
- Điện thoại: bảng rộng/nhiều cột thì kéo ngang trái–phải, có bóng mờ gợi ý ở mép.
- Dọn khai báo icon trùng trong `<head>`.
